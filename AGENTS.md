Teaching workspace for a uni Parallel & Distributed Programming module: read MISSION.md, NOTES.md and learning-records/ before teaching anything.
Scope is strictly the slides in source-materials/; outside sources (RESOURCES.md) may only explain or verify them, never add topics.
reference/course-map.html is the anchor: it maps every slide range to a lesson, holds the lesson plan and the slide errata — update it when lessons or slides change.
Lessons are short HTML files built on assets/ (style.css, quiz.js, highlight.js); exercises are single-file Java that print PASS/FAIL, run with `java File.java` (verify before shipping).
