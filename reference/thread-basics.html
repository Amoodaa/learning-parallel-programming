Thread Basics

A cheat sheet for creating, starting, and waiting on Java threads.

Create

// A: subclass Thread
class Worker extends Thread {
    public void run() { ... }
}
Thread t = new Worker();

// B: Runnable (preferred: works with pools later)
class Job implements Runnable {
    public void run() { ... }
}
Thread t = new Thread(new Job());

Start, wait, read

CallEffect
t.start()Creates a new thread that runs run(). Returns immediately. Only once per thread, otherwise IllegalThreadStateException.
t.run()Normal method call on the current thread. No new thread.
t.join()Current thread waits until t terminates. Throws InterruptedException.
t.join(ms)Waits at most ms milliseconds.

The pattern

Worker[] w = new Worker[k];
for (int j = 0; j < k; j++) {         // split + start all
    w[j] = new Worker(/* range j */);
    w[j].start();
}
for (Worker x : w) x.join();          // join all
long total = 0;                       // combine
for (Worker x : w) total += x.getResult();

Asynchronous procedure (D1 s75–79)

class FacN extends Thread {
    private int n; private long result;
    FacN(int n) { this.n = n; }
    public void run() { /* compute */ result = ...; }
    // read only after join():
    public long getResult() { return result; }
}

Sleep (D1 s50–56)

try {
    Thread.sleep(500);   // pauses the CURRENT thread
} catch (InterruptedException e) {
    return;              // interrupted: usually stop
}

Helpers (D1 s59–71)

CallEffect
setName / getName / getIdLabel and identify a thread.
Thread.currentThread()The thread running this line.
t.isAlive()Started and not finished.
Thread.yield(), setPriority(1..10)Hints only; the scheduler may ignore them.

States (D1 s66–68)

NEW → RUNNABLE → BLOCKED (lock) / WAITING (join()) / TIMED_WAITING (sleep(ms), join(ms)) → TERMINATED

Stop from outside (D1 s72–74)

// volatile: other threads SEE the write
private volatile boolean go = true;
public void run() { while (go) { ... } }
public void terminate() { go = false; }

Fair split (D2 s22–27)

int k = Runtime.getRuntime().availableProcessors();
int[] index = new int[k + 1];
for (int j = 0; j <= k; j++)
    index[j] = (int) ((long) j * N / k);
// worker j gets [index[j], index[j+1])

Pool, Callable, Future (D2 s43–72)

import java.util.*;
import java.util.concurrent.*;

class Sum implements Callable<Long> {
    public Long call() { /* work */ return s; }
}

ExecutorService pool = Executors.newFixedThreadPool(k);
List<Future<Long>> fs = new ArrayList<>();
for (int j = 0; j < k; j++)                 // submit all
    fs.add(pool.submit(new Sum(/* range j */)));
long total = 0;
for (Future<Long> f : fs) total += f.get();  // get all
pool.shutdown();                  // or the JVM never exits

For uneven work, submit many small pieces (e.g. 1,000 items each) instead of k big ones (D2 s78).
